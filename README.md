# IC Wallet Monorepo Overview / IC 월렛 모노레포 개요

This repository aggregates backend (NestJS), frontend (Next.js), and smart contract (Foundry) workspaces for the IC Wallet platform.  
본 저장소는 IC 월렛 플랫폼의 백엔드(NestJS), 프런트엔드(Next.js), 스마트컨트랙트(Foundry) 워크스페이스를 통합 관리합니다.

## Status Summary / 진행 현황 요약
- Backend: Auth JWT & OTP prototype complete; wallet module wired to mblockapi client with retry logic.  
  백엔드: 인증 JWT·OTP 프로토타입을 완료했고, 지갑 모듈을 재시도 로직이 포함된 mblockapi 클라이언트와 연동했습니다.
- Frontend: Next.js scaffold ready with bilingual landing page and roadmap sections.  
  프런트엔드: 다국어 랜딩 페이지와 로드맵 섹션을 갖춘 Next.js 스캐폴드가 준비되어 있습니다.
- Contracts: Foundry workspace initialized with placeholder NFT voucher contract & tests.  
  컨트랙트: Foundry 워크스페이스에 예비 NFT 바우처 컨트랙트와 테스트를 구성했습니다.

Refer to `docs/ROADMAP.md` and `docs/TECH-STACK.md` for detailed milestones and stack choices.  
자세한 마일스톤과 기술 스택은 `docs/ROADMAP.md`, `docs/TECH-STACK.md`에서 확인하세요.
