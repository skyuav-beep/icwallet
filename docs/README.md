# Documentation Workspace / 문서 작업 공간

Store design notes, API references, smart contract specs, and operational guides here.  
설계 노트, API 참고 자료, 스마트컨트랙트 명세, 운영 가이드를 이곳에 보관하세요.

Key expectations / 핵심 기준:
- Keep every document bilingual (EN/KR) per `AGENTS.md`.  
  `AGENTS.md` 기준에 따라 모든 문서를 영문/국문 병기로 관리하세요.
- Cross-reference `spec.md` and `TASKS.md` when updating requirements or processes.  
  요구사항이나 절차를 갱신할 때 `spec.md`, `TASKS.md`와 교차 참조하세요.
- Add dated subfolders (e.g., `2024-10/`) for major revisions or workshops.  
  주요 개정이나 워크숍 자료는 날짜 기반 하위 폴더(예: `2024-10/`)를 활용하세요.

Include an index file when the number of documents grows beyond five to help navigation.  
문서가 다섯 개 이상으로 늘어나면 탐색을 돕기 위한 인덱스 파일을 추가하세요.
