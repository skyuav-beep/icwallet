# Automation Scripts / 자동화 스크립트

Place operational and developer scripts in this directory (e.g., setup, migrations, deployment, data backfills).  
운영 및 개발용 스크립트(예: 초기 설정, 마이그레이션, 배포, 데이터 백필)를 이 디렉터리에 보관하세요.

Guidelines / 가이드라인:
- Provide a short bilingual description at the top of each script file.  
  각 스크립트 파일 상단에 영문/국문 설명을 추가하세요.
- Use executable permissions only when necessary and document required environment variables.  
  필요한 경우에만 실행 권한을 부여하고 필수 환경 변수를 문서화하세요.
- Reference related tasks from `TASKS.md` within script comments when applicable.  
  필요 시 스크립트 주석에 `TASKS.md` 관련 항목을 명시하세요.

Add usage examples in this README as new scripts are introduced.  
새 스크립트를 추가할 때는 실행 예시를 본 README에 업데이트하세요.
